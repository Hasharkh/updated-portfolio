From a Lovable design to Elementor, plus a ClearCompany jobs plugin

A full website rebuild in WordPress and Elementor based on the client's Lovable design, with UI improvements suggested and agreed page by page. The job listings live in ClearCompany, so I wrote a custom plugin that brings them into WordPress where the team can manage them.

Private client project. Details available on request.

  1. Fetch open rolesThe plugin reads job listings from the ClearCompany API.
  2. Map to a custom post typeEach listing becomes a post in a dedicated Jobs custom post type.
  3. Keep them in syncListings update in WordPress as roles change in ClearCompany.
  4. Manage in the dashboardThe team manages jobs from the dashboard like any other WordPress content.
